# The fixed prompt set for the recognition benchmark.
#
# tags<TAB>text
#
# This is not an academic corpus. It is what a Linux programmer actually
# dictates: Chinese sentences carrying English identifiers, plain Chinese,
# plain English, and the conditions a desk really has -- a quiet room, a noisy
# one, and a sentence with a pause in the middle.
#
# Read each line aloud once, in the condition its tags describe. Keep the list
# and its tags stable: a rate is only comparable across runs if the same
# sentences sit in the same bucket. Record it with scripts/record-corpus.sh.
#
#   zh / en / mixed  language of the sentence
#   technical        vocabulary this project itself dictates
#   quiet            spoken softly, as in a shared room
#   noise            spoken over background noise (traffic, music, a fan)
#   endpoint         deliberately paused in the middle
#
# Number words are written the way they are spoken. A recogniser that emits
# digits instead scores as an error on purpose: the text that lands in the
# editor is what is being measured, not what it meant.
